# Callback vs Webhook
Perharps one of the most useful differentiator of callback and webhook that I could find in the web is from FastAPI documentation. 
- [Callback](https://fastapi.tiangolo.com/advanced/openapi-callbacks/#create-the-callback-path-operation)
- [Webhook](https://fastapi.tiangolo.com/advanced/openapi-webhooks/#webhooks-steps)
And somehow the main take away is that callback is a bit more sync-y compared to webhook.
